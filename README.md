# Manual interactivo de Tarot Rider–Waite–Smith

Aplicación web en español para consultar las cartas, explorar su simbología y practicar tiradas. La interfaz y la lógica están en [index.html](index.html), y las imágenes se encuentran en [img](img/).

Para abrirla en local, ejecuta desde la raíz `python3 -m http.server 8000 --bind 127.0.0.1` y visita `http://127.0.0.1:8000`. Para cambiar el contenido de una carta o una tirada, edita el HTML y conserva las rutas relativas de las imágenes.
